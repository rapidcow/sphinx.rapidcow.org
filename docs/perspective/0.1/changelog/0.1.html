Release 0.1#

Release 0.1.0 (in development)#

Author:

rapidcow <thegentlecow@gmail.com>

This documentation didn’t exist before this release, so these changes are kept here exclusively for the record!

Renaming#

Mostly shortenings, meh

  • psp.processors.json_processor -> psp.serializers.json

  • psp.extensions -> psp.ext

  • psp.main -> psp.cli (will be a package with messed-up functions for user-friendliness + show-off)

Attribute protocol!#

New class: Configurable!#

Extensions!#

  • New modules (mention this first): captions and metadata!

  • See the extensions tutorial

From datatypes to filetypes#

New class: InferenceManager!#

JSONLoader#

  • JSONLoader.load() no longer takes a file path, JSONLoader.load_json() method is added (re-added?) as a hook for loading a JSON archive

  • Removed the date argument in JSONLoader.load() and JSONLoader.load_data()

  • JSONLoader.load() or JSONLoader.load_data() now returns a generator. Use list(loader.load()) to obtain an identical result to before (or alternatively, use the load_json() function)

  • Removed the check_panel_duplicates option given that JSONLoader.load() now returns a generator and the option works on top of the fact that panels are loaded entirely a list. Instead, when you do load from a list, use a function (copied directly from the code):

    def check_duplicates(panels):
    # Make a dict with date as keys and indices as values
    panel_dict = collections.defaultdict(list)
    for index, panel in enumerate(panels, start=1):
        panel_dict[panel.date].append(index)

    # We know there are duplicates if any list has more than one index
    for panel_date, indices in sorted(panel_dict.items()):
        if len(indices) > 1:
            # Sorting 'indices' is trivial here
            # (they can only appear in increasing order)
            index_str = (f"{', '.join(f'#{i}' for i in indices[:-1])} "
                         f"and #{indices[-1]}")
            raise ValueError(f'panels {index_str} share the '
                             f'same date ({panel_date})')

    then something like

    with open(file, encoding='utf-8') as fp:
    panel_list = list(loader.load(fp))
check_duplicates(panel_list)

    should work.

  • parse_datetime(s, tzinfo, fold) parameters are all positional! (parse_time(s, tzinfo, fold) similarly)

  • paths option is removed. to extend the lookup paths, you may override split_data(), though it is not recommended as lookup paths should be sufficiently contained within the JSON archive

  • parameters of process_entry() are now (entry, panel, attrs) instead of (panel, entry, attrs). No idea why I put panel first before given how important entry is compared to the rest.

  • IMPORTANT!!! now tz and paths are all guaranteed to be set by split_data()

  • loader: attrs are never copied unless absolutely necessary

JSONDumper#

  • a completely revamped interface!!

  • dump() no longer takes a file path

  • dump_json(data, fp) for interface

    • data can now be any iterable and JSONDumper won’t put them all in a list beforehand!

  • handle_datetime() and handle_timezone() removed, instead now there’s write_entry_date_and_time() and format_timezone()

  • input paths are no longer precomputed, see get_input_path() for all related functions

Streaming interface#

Now you can stream data with entries! though you would be responsible for closing the file-like object…

This can be helpful for remote access. If one day someone decides to implement it, that is.

  • Entry.stream_data() should be consistent with Entry.get_data(). That is, when get_data() returns str, stream_data() should stream str. And likewise for bytes.

  • Entry.stream_raw_data() should be consistent with Entry.get_raw_data().

  • For operations possible with file-like objects, refer to the io module.

Panel and Entry#

  • set_source() no longer accepts None, use set_raw_data(b'') instead

  • Entry has __init__(time, /, insight=False)

  • Panel has __init__(date, /)

  • Entry.date_time renamed to Entry.time

  • Entry.has_raw_data() is removed due to being too ambiguous

    get_raw_data() still retrieves the raw data depending on whether the data is in-memory or stored in a file but has_raw_data() gives off the impression that get_raw_data() might return None. instead, use not has_source(), since it’s now impossible for source and raw data to be set at the same time.

  • Entry.load_data() is removed

    having raw data AND source path was simply dumb. what happens when the file is changed externally? our current implementation says to prioritize the raw data over source path, but doesn’t that make the source path essentially ineffective?

    in case anyone REALLY wants to load the data into memory, just setting the raw data explicitly will do:

    entry.set_raw_data(entry.get_raw_data())

  • Entry.export() is removed. Now with the new streaming interface, the lines:

    entry.export(fp)    # fp is a writable binary file-like object
entry.export(path)  # path is path-like

    may be replaced with:

    with entry.stream_raw_data() as fsrc:
    fp.write(fsrc.read())

with open(path, 'xb') as fp:
    with entry.stream_raw_data() as fsrc:
        fp.write(fsrc.read())

    To copy by chunks, you can replace fp.write(fsrc.read()) with psp.util.copyfileobj(fsrc, fp) instead (psp.util.copyfileobj() directly uses shutil.copyfileobj(), by the way).

    The difference is that it is now up to you to decide how exporting should work! Should it write to a different encoding or do you want to keep the raw data verbatim? Should it read in all the data at once or write one chunk at a time?

    I can’t answer all these questions all at once for everyone, so I’m leaving them to you now.

  • Entry.set_source() no longer checks for file existence

Main program#

you can now create projects (STILL very much WIP though)

hacky imports are still a thing (BWAHH WHYYY)

Other Changes (TEMP)#

  • util.panels_equal() and util.entries_equal() are removed, use

    p1 == p2
e1 == e2

    instead of

    panels_equal(p1, p2)
entries_equal(e1, e2)

    • Most of equality is implemented with the equality of each member (as described in the types module), with the exception of the Entry class’s time attribute, which is always converted to UTC time before comparison. (This is to avoid shenanigans of interzone comparison (ignores the fold attribute) and intrazone comparison (always unequal when utcoffset() depends on the fold attribute).)

  • __init__.py no longer imports the types.Panel or types.Entry class. You have to import explicitly from psp.types now.

  • New convenience functions added! util.fileobjequal() and util.copyfileobj()

  • change arguments of the JSONLoader.process_entry() method from (panel, entry, attrs) to (entry, panel, attrs)

    • it makes more sense as it follows logical order: the part being actually processed (entry) and the part being accessed (attrs)

  • make loader and dumper only accept file objects

    • load_json() and load_json() being sole exceptions

  • find_paths: a public generator

  • base_dir in JSONLoader and JSONDumper now take None which activates this sort of “restricted” mode that causes an error to be raised whenever access to the file system is attempted
