psp.stringify — Format panels and entries#

This module defines classes PanelFormatter and EntryFormatter for formatting panels and entries as strings that mimics the interface from the app Perspective.

Base class#

class psp.stringify.Formatter(abc.ABC)#

An abstract base class for formatter classes.

__init__(self, width=80, wrapper=None, **options)#

Initialize formatter.

The options are passed on to configure().

configure(**options)#

Configure options. The following is a table of all options:

Option

Description

Type

Default

indent

String to prepend to each line.

str

''

strlen

Function that takes a str and returns it length.

callable

len

line_callback

Function that is called on each line.

callable

str.rstrip
abstract format(obj)#

Takes an object as an argument and returns a formatted string representation of that object.

property wrapper#

A wrapper object that implements a wrap() method and has a writable attribute width. The wrap() method takes a string and returns a list of lines, each with length no more than width. Set this to None to disable line wrapping.

property width#

An int representing the maximum width of each line. Must be no less than 0.

Protected attributes for subclassing:

_all_options#

A set of all option names. Subclasses should update this so that configure() knows what options are valid and what aren’t.

_options#

A dict of the option names and values.

Protected methods:

_is_wrapping_disabled()#

Return whether text wrapping will be used.

_wrap(text)#

Low-level wrapping.

wrap_paragraph(text, *, prefix='', fillchar=' ')#

Wrap left-aligned text.

center_paragraph(text, *, fillchar=' ')#

Wrap centered text.

Formatter implementations#

class psp.stringify.PanelFormatter(Formatter)#

Formatter for Panel objects.

format(panel)#

Format a panel.

set_entry_formatter(formatter)#

Set the entry formatter for format() to use.

get_entry_formatter(formatter)#

Get the entry formatter for format() to use. If set_entry_formatter() was never called, an EntryFormatter instance is automatically created.

configure_entry_formatter(entry_formatter, panel)#

When format() is called, its argument panel as well as the entry formatter are passed to this function. Options to keep the entry formatter consistent with the panel are set by default.

class psp.stringify.EntryFormatter(Formatter)#

Formatter for Entry objects.

format(entry)#

Format an entry.

Convenience Interface#

psp.stringify.format_panel(panel, *, entry_formatter=None, **options)#

Format a panel. This calls PanelFormatter.format(). If entry_formatter is provided, it is set by calling PanelFormatter.set_entry_formatter(). The options are passed to the constructor of PanelFormatter.

psp.stringify.format_entry(entry, **options)#

Format an entry. This calls EntryFormatter.format(). The options are passed to the constructor of EntryFormatter.

psp.stringify.print_panel(panel, file=None, **kwargs)#

Calls print(format_panel(panel, **kwargs), file=file)

psp.stringify.print_entry(entry, file=None, **kwargs)#

Calls print(format_entry(entry, **kwargs), file=file)
